# The Mealtally name and logo

The Mealtally **code** is licensed under the AGPL-3.0-only. The **name "Mealtally" and the Mealtally logo** are not:
the code licence gives you no rights to them. "Mealtally" is an unregistered trademark of the project's maintainer.

This keeps the name meaning one thing: the software from this project.

## What you may do without asking

- Say that your service or product **runs on**, **is built with** or **is compatible with** Mealtally, in plain text.
- Run an unmodified copy of Mealtally (an official release or the `main` branch) under its own name and logo, for
  example for your own restaurant.
- Use the name and logo to talk about the project: articles, talks, tutorials, links.
- Keep the "Powered by Mealtally" line that the software shows.

## What needs a different name and logo

If you **change the code and distribute it or offer it to others as a service**, use your own name and your own logo.
You can still say it is "based on Mealtally".

Also, please don't:

- use "Mealtally" or a confusingly similar name in your product, company or domain name,
- use the logo in a way that suggests the project endorses you, or change the logo and still call it Mealtally.

This project is not affiliated with any other business that uses a similar name.
