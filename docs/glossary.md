# Glossary for UI text and translators

Use one word for one thing. This list applies to everything a user sees or hears.

| Use | For | Don't use |
|---|---|---|
| restaurant | the customer of Mealtally: a restaurant, mess, tiffin service or canteen | business, outlet, tenant, vendor, or kitchen when it means the whole restaurant |
| kitchen | the place where food is cooked | |
| sign in, sign out | the actions | log in, login, log out |
| sign-in | the noun: "Staff sign-in" | login |
| staff account | a person's staff access | staff login |
| plan | what the restaurant sells | |
| pass | what a customer has bought | plan, subscription |
| subscription | a wallet plan in the Preview wallet module only | |
| meals left | what remains on a pass | balance, credits |
| adjust meals | changing the meals on a pass | adjust credits |
| undo | taking back a redeemed meal (button and list) | reverse |
| void | cancelling a receipt or payment | undo |
| wallet balance | money in a Preview wallet | |
| pick-up | collecting an order | pickup |

## Writing rules

- Use sentence case for headings, buttons, plan names and demo data.
- Don't use em dashes in sentences. An en dash is fine in a number range such as 12:00–15:00.
- Don't use arrows or ticks as decoration. Write "Back to orders" and "from 2 to 3".
- Don't use exclamation marks or promotional words.
- Write statements, not questions you answer yourself. Standard labels such as "Forgot your password?" stay.
- Errors and empty states say what happened and what to do next, in one or two short sentences.
- Keep wording global. Country-specific items such as UPI stay behind the country setting.
